连接

这里填的是路由器上 nikki(mihomo)的 external-controller 地址和密码。保存前会先连一次验证,密码只存在你自己的 data/config.json。
nikki 改了地址 / 密码 / 认证,各自在哪里改?
· 接口地址 + 密码(secret):就是上面这两项。nikki(mihomo)的接口没有用户名,只有「地址:端口 + 密码」。改了之后这里同步改,状态栏左下角的圆点会变灰/红并提示 401 或连不上,点它也能回到这里。
· 代理认证的用户名和密码(nikki 的 mixed-port 设了 user:pass):只有「下载 GeoIP 库走代理」会用到,在 设置 → 目的地数据库 里填。
· AdGuard Home 的用户名和密码:在 设置 → DNS 里填。
· 这些都只存在你自己的 data 目录里,不会出现在诊断包和备份里。

面板自己的访问地址和端口

端口被别的程序占用时在这里换一个。改的时候会先在新地址多开一个监听、旧的保留,页面带你跳到新地址点一下确认才正式生效;120 秒内没确认会自动撤销,不会把自己锁在外面。(用 docker 的 host 网络,所以改的是容器里的监听,不需要改 compose。)

机场归类规则

默认按节点名里竖线(| 或 ｜)前面的部分当机场名,比如「CF | 香港 01」归到 CF。名字里没有竖线的节点,或者想合并、改名,在这里写规则,每行一条:关键字=机场名,节点名包含关键字就归到该机场。规则优先于默认。

应用识别规则

面板内置了一份域名 / 端口特征库(流媒体、网盘、P2P、代理隧道等)。这里可以补充自己的规则,优先于内置库。每行一条:域名关键字=应用名|类别,类别可省略。关键字不含点时按「包含」匹配,含点时按域名后缀匹配。
例:mycdn.example.com=公司内网|办公 / 开发　quark=夸克网盘|网盘 / 云存储

DNS

只读接入:面板读取 AdGuard Home 的统计和被拦截的查询,不会修改它的任何设置。账号密码只保存在 data 目录的数据库里,页面不会再显示。
路由器自带的 dnsmasq
没用 AdGuard Home 的话,DNS 统计来自 dnsmasq 的查询日志:路由器把日志转发给面板(先在「路由器日志」里开启接收),面板只统计、不改路由器。查询日志量大,面板收到后直接汇总成计数,不会逐条塞满日志表;DHCP、警告、错误等其它 dnsmasq 日志照常保存,诊断包也会带上。在路由器 SSH 里执行一次(想关掉就把 1 改成 0):
自定义 DNS 服务器
填名称、地址和端口(53、5353、AdGuard 的其它端口都行)。面板定时给它发一个真正的 DNS 查询(UDP),记录有没有响应和耗时,只是探测,不改任何东西。可以加路由器自己、运营商 DNS、223.5.5.5、1.1.1.1 等来对比。

目的地数据库(GeoIP)

用来统计流量去了哪些国家 / ASN。数据库放在 data/geoip/(名字里带 country / asn 的 .mmdb 文件,DB-IP Lite 或 MaxMind GeoLite2 均可),也可以在这里一键下载(GitHub 上的 GeoLite2 镜像,失败再试 DB-IP Lite)。下载由路由器上的面板发出;路由器直连不通时,在下面设置下载代理。注意:经代理的流量看不到真实目的地,只能看到直连和非 fake-ip 的连接。
下载代理
路由器直连下载站点失败时,填一个 HTTP 代理(不支持 SOCKS)。nikki 开了认证的话写成 http://用户名:密码@127.0.0.1:7890。只保存在 data 目录,页面不会再显示;留空保存 = 清除。来源依次尝试:GitHub(GeoLite2 镜像)→ DB-IP Lite。

机场套餐

nikki 里读得到机场官方数据的(已用、总量、到期),会自动加进套餐用量,不用在这里填。下面只在读不到官方数据、或想指定「每月重置日」让面板预测超额时才需要设置(总量填 0 = 用官方的数字)。每个机场选套餐类型:「每月重置」(填月流量和重置日)或「一次性总量」(填总量,可填起算日,不填就从有记录的第一天算)。「到期日」留空 = 永不过期;填了会在到期前 7 / 3 / 1 天提醒续费。流量单位可选 GB 或 TB(1 TB = 1024 GB)。面板按已统计的流量估算用量与预计用完时间,和机场后台可能有出入;用量到阈值会触发「套餐用量」告警。

备份与恢复

外观(卡片显示 / 顺序 / 主题)会自动同步一份到服务器,换浏览器或清缓存后会自动取回。下面可以把全部设置导出成一个文件存着,设置丢了就导入它。备份包含:外观、告警规则与推送渠道、AdGuard、机场套餐、周报、机场归类规则、应用识别规则、设备名。流量统计数据不在其中(它们存在 data 目录里,更新容器不会丢)。

周报与监控

Prometheus 指标
抓取地址 /metrics(文本格式)。已设置访问密码时,Prometheus 可用环境变量 METRICS_TOKEN 指定的口令抓取:Authorization: Bearer 口令 或 /metrics?t=口令。包含总 / 设备流量、实时速率、连接数、节点延迟、TCP 重传率、告警数。

安全与隐私

访问密码:设置后,打开面板和调用接口都要先登录。面板里能看到每台设备访问过的域名,建议设置。密码只保存加盐哈希(data/auth.json);连续输错 5 次会锁定 1 分钟。
只读账号
再设一个只读密码,给家人 / 朋友 / 公共屏幕用:登录后只能看流量、设备、日志,不能改任何设置,也不能导出备份和诊断包、看容器日志。登录页还是一个密码框,输哪个密码就以哪种身份进入。不能和管理员密码相同;留空保存 = 关闭只读账号。
登录页壁纸
设置了访问密码后,登录页可以像路由器 Argon 主题那样显示一张壁纸(登录框为毛玻璃)。图片会在浏览器里自动压缩后存到面板的数据目录;登录前任何人都能看到这张图,所以别用私人照片。也可以选「必应每日图片」定时自动更换(需要面板能访问 bing.com;走的是 GeoIP 下载那个代理设置)。壁纸不包含在备份里。

节点测速(可选)

nikki 只给策略组里的节点做延迟测试,其它节点没有测速数据,「节点评分」和「网络质量」就看不到它们。开启后,面板会定时让 nikki 给最近 24 小时真正用过的节点测一次延迟(只发测速请求,不改 nikki 的任何配置),结果进 nikki 的测速记录,再被面板读回去算评分。只测在用的节点,请求量很小。
每分钟测一轮,每轮最多测个节点

路由器系统日志

让路由器把系统日志(内核、拨号、DHCP、各种服务)通过 UDP 转发给面板,面板存进自己的数据库,按「保留天数」和「最大条数」自动清理。不往路由器的闪存/硬盘写日志(路由器自己的日志只在内存里),面板只占一点数据盘空间,默认 7 天约几十 MB 以内。只接受内网来源;每秒最多入库 300 条。UDP 偶尔会丢包,面板重启期间的日志也收不到,这是排查问题用的,不是审计日志。出现内存不足、文件系统错误、内核崩溃等严重信息时会推送告警。
UDP 端口保留天,最多条

Docker 容器

  
在面板里看路由器上 Docker 容器的运行状态、CPU / 内存、日志,容器意外停了会告警;可选地允许启动 / 停止 / 重启。面板不挂载 docker.sock(挂了等于把整台路由器的 root 权限交给它),而是通过一个受限的 docker-socket-proxy 访问 Docker:代理只放行你指定的几类请求,面板读不到容器的环境变量(里面常有密码),也不能创建 / 删除容器或进入容器执行命令。
