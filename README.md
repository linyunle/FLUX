# FLUX

<img src="assets/logo.png" width="96" alt="FLUX">

FLUX —— 给 nikki(mihomo)用的流量面板:按 **设备 / 机场 / 节点 / 策略组 / 规则 / 访问目标** 统计流量,看小时、天趋势。
数据只存在你自己的路由器上(SQLite),不联网上报。

## 功能
- 设备:点开设备列表里的一台,看这台设备的详情(趋势、直连/代理占比、访问目标、用到的节点、策略组、规则);在概览筛选某台设备时自动隐藏与它无关的全局内容;顶部统计栏滚动时固定;同一台设备的 IPv4 / 多个 IPv6 按 MAC 合并;可改名,可粘贴 `uci show dhcp` 批量导入名字;顶部可多选筛选设备
- 实时:每 2 秒刷新,直连 / 代理速度分开统计,另有连接数;左侧栏常驻四张实时小卡(总速度、直连、代理、连接数);概览里「实时速度 / 直连速度 / 代理速度 / 最活跃设备 / 最活跃节点」都是独立卡片
- 概览卡片可自由排列:「设置 → 外观 → 概览卡片」里每张卡片单独设宽度(1/4 ~ 整行)、图表高度、显示/隐藏、顺序,同一行放得下的卡片自动并排
- 设备流量消耗 Top(概览卡片,可切 全部/代理/直连,点一行看该设备访问的域名);访问目标 Top 和域名清单点一行看是哪些设备访问的;节点页点一个节点进入详情(连接的设备、域名、策略组、规则、趋势);搜索访问目标时概览只留统计卡片和访问目标 Top
- 外观:侧栏每个内容(实时卡片、连接状态、设备筛选、主题切换、版本号)可单独显示/隐藏,侧栏可收起成窄条;卡片阴影和透明度可调
- 趋势:堆叠柱 / 分组柱 / 折线 / 面积四种样式,可单独设上行、下行颜色,可把上行和下行拆成两张图;24 小时 / 48 小时 / 7 天(按小时)、14 / 30 天(按天),带表格视图
- 域名清单:谁访问过哪些域名、走直连还是代理、最近哪天,可合并子域名,可导出 CSV(按连接记录统计,不是 DNS 查询日志)
- 规则与策略组:点一行就能钻取,并显示每个策略组/规则实际走了哪些节点
- 机场与节点:按节点名自动归类机场(取「机场名 | 地区 01」里竖线前面的部分,也可以写规则),看每个机场/节点的下行、上行、合计和趋势;顶部可按机场筛选,概览、设备、域名都会跟着只看这个机场;时间范围有「本月」
- 界面:左侧栏导航(概览/机场/节点/设备/域名/规则策略/设置),小卡片布局;「设置 → 外观」可切换 6 套预设主题、跟随系统/浅色/深色、自定义强调色和上下行颜色、紧凑/标准/宽松密度、页面宽度、圆角、字号,概览卡片可隐藏和调序;只保存在当前浏览器
- 应用识别 / Top Talkers:按域名(SNI)特征库 + 端口把流量归到具体应用和类别(流媒体、网盘、P2P、代理隧道等),点一行看是哪些设备在用;「设置 → 应用识别」可加自定义规则。这不是真正的深度包检测(面板只能读到 nikki 接口,看不到加密内容)
- 流量堆叠趋势:按小时的堆叠面积图,可按 设备 / 节点 / 去向 / 应用 / 类别 / 协议 堆叠,悬停看每个系列的值,标出峰值
- 网络质量 QoE:节点延迟 / 抖动 / 超时率(来自 nikki 测速)、路由器 TCP 重传率(内核全局计数)、出口隧道协议分布;不提供应用层丢包率和分设备 RTT(数据拿不到)
- 访问密码 / 隐私模式:「设置 → 安全与隐私」可设置登录密码(加盐哈希,输错 5 次锁 1 分钟),也可用环境变量 PANEL_PASSWORD;隐私模式把域名 / 目标 IP 模糊显示,悬停才显示
- 视图预设:概览顶部一键切换 全部 / 总览 / 排障 / 安全 四组卡片;顶部筛选条的标签可逐个取消,也可「清除全部」
- 连接设置:在网页里填 nikki API 地址和密码,保存前会先验证
- 新版本提示:查 GitHub Release,更新只需一条命令

## 部署(路由器上)
```sh
mkdir -p /mnt/data/docker/flux && cd /mnt/data/docker/flux
# 放入 docker-compose.yml和 .env(可选)
docker compose up -d
```
打开 `http://路由器IP:8099/`,右上角「连接设置」填 nikki API(同机一般是 `http://127.0.0.1:9090`)和密码。

## 更新
```sh
cd /mnt/data/docker/flux && docker compose pull && docker compose up -d
```
数据在 `./data`,更新不丢。旧版 v1 的数据库会自动升级。

## 发布新版本(开发者)
推一个 `v*` 标签,GitHub Actions 会构建 amd64 + arm64 镜像并推到 `ghcr.io/<owner>/flux`,同时创建 Release。
首次发布后,到仓库 Packages 页面把该包设为 Public,路由器才能免登录拉取。

## 设备主机名
容器会只读挂载路由器的 `/tmp/dhcp.leases`,动态分配地址的设备如果上报了主机名会自动显示;静态表可在页面里「设备 → 导入设备名」粘贴 `uci show dhcp` 批量导入。

## 精度说明
- 每 10 秒采样一次 `/connections`,短于一个周期的连接看不到,连接关闭前最后一个周期的字节会丢
- 不经过 nikki 的流量(绕过大陆 IP、局域网内互访、路由器自身)统计不到;设置 `WAN_IFACE` 可在页面看到 WAN 实际总量对账
